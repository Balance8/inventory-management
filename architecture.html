System Architecture

Factory Inventory Management

A full-stack demo: a Vue 3 single-page app communicates with a FastAPI service over HTTP. Data is held in memory and seeded from JSON files at startup — no database, no auth, optimized for local demos.

Overview

Two processes, one network call away.

Frontend
Vue 3 SPA
localhost:3000 · Vite dev server

Composition API throughout. 7 views, 9 modal/UI components, shared filter state via composables.

Backend
FastAPI Service
localhost:8001 · Uvicorn

Pydantic-validated REST endpoints. In-memory filtering on data loaded once at startup.

Data
JSON Fixtures
server/data/*.json

7 files seed the in-memory store. Mutations are ephemeral — restart reloads from disk.
